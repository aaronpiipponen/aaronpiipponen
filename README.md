## About

BSc student in Computer Science and Biomedical Engineering (Biomedical Devices and Systems) at Tampere University.

My projects focus on machine learning, backend systems, and developer tooling for structured agent workflows.

## Main projects

- [`course-explorer`](https://github.com/aaronpiipponen/course-explorer) explores university curriculum data through a React browser application, a read-only FastAPI backend, PostgreSQL and `pgvector` search, adaptive admission control, and offline prerequisite inference. The [course-explorer live site](https://course-explorer.duckdns.org/) hosts Tampere University curriculum data and is fully functional.
- [`my-workflow`](https://github.com/aaronpiipponen/my-workflow) delivers a shared OpenCode agent instruction set across checkouts through symlinks, section-level role injection, phase-bounded planning, and companion runtime plugins. I use it to orchestrate development on `course-explorer`.
